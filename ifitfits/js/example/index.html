ifitfits · host example

A tiny web host that owns focus and drives the ifitfits library (../ifitfits.js) — the same API as the Go package. Click a tile to focus it; drive it with the keys below. The engine renders nothing itself: this page draws vp.Tiles() / vp.Stacks() / vp.Caret().
