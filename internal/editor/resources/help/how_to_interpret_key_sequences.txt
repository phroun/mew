==== How to interpret Key Sequences ====

=== Sequences ===

Most software today uses a combination of single keypresses (such as
"Enter", "Delete" or "F1"), and a set of key CHORDS (such as Ctrl+B)
to quickly access frequently used functions.

By contrast, a **Key Sequence** is a series of chords or individual
keys that are pressed in a certain order.

**mew** makes use of both **Chords** and **Key Sequences**, and its default
key mappings are organized into command families in much the same spirit
as WordStar and JOE.  To learn more of the reasoning and history behind
these ideas, see [[About Key Chords and Sequences]].

To become good at **mew**, you will want a basic idea of how the
**Key Sequence Processor** works, and an understanding of the conventions
we have chosen to describe the Chords and Sequences in our help screens
and manual.  The rest of this topic is devoted to that purpose:

=== Normal Keys ===

== Alphanumeric Keys ==

The numbers 1 through 9 and 0, and the letters A through Z are represented
in the mew documentation with their basic symbol.  Letters are generally
shown in uppercase, and only differentiated in places where a distinction
is meaningful.

The numbers 1 through 9 and 0 are matched with symbols that are produced
by pressing the same key while holding in shift.  In mew, we often refer to
this combination of shift and a number by simply referring to the symbol:

=== Special Keys ===

First, lets cover the names of the special keys:

[[keys#|esc]] — Escape, usually the top left key on your keyboard.

  - On international keyboards this may be labeled with
    the ⎋ symbol (circle with arrow pointing out the top left.)

[[keys#|tab]] — Tab, to the left of the top row of letter keys.

  - On many keyboards this may be labeled with the
    ↹ symbol. (left and right arrows with vertical stops.)

[[keys#|del]] / [[keys#|back]] — The key that removes the most recently typed character.

  - On IBM PC compatible computers this is usually
    labeled "Backspace" or simply "<---"

  - On Apple Macintosh computers this is labeled "delete"
    or ⌫ (left pointing tag with an X in it.)

[[keys#|fdel]] — Called "forward delete", removes the next character past the cursor.

  - On notebooks this is often achieved by holding "fn" while pressing
    the regular "Backspace" or "delete" key.

  - On IBM PC compatible computers this key is usually labeled "Del"

  - On Apple or International keyboards, this is often
    represented by ⌦ (right pointing tag with an X in it.)

[[keys#|return]] / [[keys#|enter]] — On the right end of the home-row, starts a new line.

  - Computers with a numeric keypad may have an additional smaller key
    also labeled "enter" which is not the one being referred to in mew.

  - May be labeled ↩ or ⏎ (a down then left arrow with a ninety degree bend.)

[[keys#|space]] — The long spacebar at the bottom edge of the keyboard.

  - Sometimes represented as the ⎵ symbol.

[[keys#|left]], [[keys#|right]], [[keys#|up]], [[keys#|down]] — The Arrow Keys

  - Usually near the bottom of the keyboard, on the right end of the row
    containing the spacebar.

[[keys#|F1]] through [[keys#|F12]] — The numbered Function Keys.

  - On Apple Macintosh computers and most notebook PCs, you may need to
    hold down the "Fn" key while activating these in order to press the
    actual "F" key, since a plain press may be mapped to special functions
    such as brightness adjustment, media player, and volume control.

=== Modifier keys: ===

**"^"** or **"C-"** — The Control Key

  - Often labeled ⌃ or ^ or Ctl or Ctrl.

  - On traditional terminals this key was left of the letter "a", on the
    home row.  Most modern computers place the relatively useless, and
    highly accident-prone Caps Lock key there instead.  It is a common
    modification to remap the Control back to the physical Caps Lock key
    for improved ergonomics, but this must be done through the host
    Operating System, and is not a built-in **mew** option.

**"S-"** — The Shift Key

  - Often labeled ⇧

  - Located on either end of the bottom row of letters.  The two Shift
    keys are interchangeable in **mew**, so use the one that is easiest
    to reach in combination with the desired key or keys.

**"M-"** — The Meta Key

  - Often labeled ⎇ Alt or ⌥ Option.

  - Usually located one or two keys left of the space bar.

**"G-"** — The Glyph Key

  - Used to produce third layer international symbols.

  - Often labeled ⎇ AltGr.

  - Labeled "Greek" (or "Front") on the legendary Space Cadet Keyboard.

**"s-"** — The Super Key (or Command, or System)

  - Often labeled ⌘, ❖ or ⊞.

  - Usually located one or two keys left of the space bar.

  - Its function is mostly defined by the host Operating System.

**"H-"** — The Hyper Key

  - Only exists on the legendary Space Cadet Keyboard.

  - The graphical versions of **mew** emulate it whenever you hold either:
    both the LEFT AND RIGHT Alt or Option keys at the same time,
    or both the LEFT AND RIGHT Control keys at the same time.

**"fn"** — Function or Globe

  - Often represented by 🌐.

  - Usually located at the bottom left corner of the keyboard.

=== Chords: ===

A chord is when one or more modifier key is held down while another
regular key is pressed:

== The Control Key ==

When combined with a letter, number, or symbol, shown as a ^ prefix:

  - ^X = Ctrl+X
  - ^/ = Ctrl+Slash
  - ^3 = Ctrl+3

When combined with named keys, we use the C- prefix:

  - C-Down = Ctrl+Down Arrow
  - C-F4 = Ctrl+F4 (4th Function Key)

For historical reasons, several Control chords are equivalent to other keys
or other chords.  See [[Historically Dead Chords]].

== The Shift Key ==

__**Shifted Numbers and Symbols**__

Whenever Shift is combined with a number or symbol, we just show the
resulting symbol:

    # = Shift+3

__**Shifted Letters**__

The **mew** keybinding system is case-insensitive by default.  However, if
two bindings exist which differ only by case, then that set of bindings is
treated case-sensitively, and which action results depends on whether the
Shift key was held.

Historically, many home computers had only uppercase glyphs before lowercase
character sets were added (TRS-80, Apple 2 and 2+, Commodore PET), and since
nearly all keyboards have the keys labeled with uppercase legends, and owing
to the fact that nearly all shortcut keys are unshifted, it would look
unfamiliar to write them all in lowercase, so the default **mew** configuration
files and documentation regularly use UPPERCASE for keys, relying on the case
insensitive matching rather than requiring "Shift", and the lowercase form is
only used to indicate "Unshifted" in cases where two distinct bindings exist
and a difference must be shown, and in such cases the uppercase form is
only accessible with Shift (or Caps Lock if you're nasty.)

== The Combination of Control + Shift ==

Alphabetic Control keys are always shown in uppercase form.

Traditional terminals could not differentiate between Control+Letter and
Control+Shift+Letter.  Modern Terminals, with extended protocols, and the
graphical versions of **mew**, do support a distinction of Control+Shift, but
when this is used with a letter we write out with the "S-" prefix:

    S-^X = Shift+Control+X

When Control is combined with a shifted number or shifted symbol, we just
show ^ with the resulting symbol:

    ^# = Ctrl+Shift+3
    ^{ = Ctrl+Shift+[

Historical keyboard circuits couldn't tell apart certain Control+Shift chords
from plain Control chords.  See [[Historically Dead Chords]].

== The Meta Key ==

In the default **mew** control scheme, the Meta key is mostly unbound.

In the few cases it is used, we offer "esc" prefixed alternatives instead.

On the Windows NT graphical version of **mew**, we use it as an escape hatch
in combination with several common patterns:

  M-^X = Cut to Operating System Clipboard
  M-^C = Copy to Operating System Clipboard
  M-^V = Paste from Operating System Clipboard
  M-^A = Select All
  M-^- (Meta+Minus) = Reduce Size
  M-^= (Meta+Plus) = Increase Size

== The Super Key ==

In the default **mew** control scheme, the Super key is mostly unbound.

On the macOS graphical version of **mew**, we use it to support several common
patterns:

  s-X = Cut to Operating System Clipboard
  s-C = Copy to Operating System Clipboard
  s-V = Paste from Operating System Clipboard
  s-A = Select All
  s-H = Hide mew
  s-- (Super+Minus) = Reduce Size
  s-= (Super+Plus) = Increase Size

== The Hyper Key ==

In the default **mew** control scheme, the Hyper key is unbound.
